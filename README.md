# CoreRandom
A Library made in core for core that generates random number. 

# Stack

CoreRandom is made in core, CoreRandom is really simple and easy to understand unlike the other random libraries. 

# How to use it

you have to first install corerandom into your project by running the following command ```core install github.com/CoreLanguage/CoreRandom``` after that you can go ahead and import in any of your files. you can see example down in the example heading.

# Example
```
import corerandom
func main() {
say corerandom.number()
}
```
